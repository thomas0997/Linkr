# Linkr

A daily puzzle game where players guess the hidden word or phrase connecting three images. Inspired by the Guess the Link format from the Sidemen YouTube channel.

Live example: a sole of a shoe, Brussels sprouts, and a deli shop all connect to **Capital Cities** through wordplay (Seoul, Brussels, Delhi).

---

## What it is

Linkr is a full-stack web application built in Java with Spring Boot. Players are shown three images per level and must figure out what they all have in common. The connection is always hidden through wordplay, homophones, or cultural references. Questions are generated by an AI and reviewed by an admin before going live, so every puzzle is hand-approved for quality.

The game tracks progress, awards coins based on how quickly a player solves each level, and lets players spend coins on clues or letter reveals when they get stuck. A leaderboard ranks players by how far they have progressed.

## Features

**For players**

- Per-letter input boxes styled like 4 Pics 1 Word, showing word length as a hint
- Three progressive clues per level (2, 4, and 8 coins each)
- Letter reveal clue that exposes one random letter for 10 coins
- Coin rewards based on number of tries used (5 coins for first try, scaling down)
- Guest mode with cookie-based persistence so progress survives page refreshes
- Leaderboard sorted by level reached, with a podium for the top three players
- Profile page showing current level, coins, levels completed, and leaderboard rank

**For the admin**

- TOTP two-factor authentication (works with Microsoft Authenticator or any RFC 6238 app)
- Password plus authenticator code required at login
- Admin panel to generate questions via Groq AI, review them, and approve or reject
- Per-image re-fetch: swap out any of the three Unsplash images without regenerating the whole question
- Rejected answers are stored and fed back to the AI on subsequent generations to avoid repeats
- Live active player counter showing how many players have been active in the last 5 minutes
- File upload support as an alternative to Unsplash URLs

---

## How Questions Are Generated

1. The admin clicks Generate in the admin panel
2. A prompt is sent to the Groq API with examples, rules, and a list of previously rejected answers
3. The AI returns a JSON object with an answer, three image search keywords, three clues, and reasoning for each image
4. Each keyword is sent to the Unsplash API to fetch a real photo
5. The admin reviews the question, can edit any field, and can swap out individual images
6. Clicking Approve saves the question to the database at the chosen level number
7. Players see the question when they reach that level

---

## Security

- Admin login requires both a static password and a time-based one-time password that changes every 30 seconds
- The TOTP implementation is written from scratch using HmacSHA1 and base32 decoding, with a plus-or-minus two window to account for clock drift
- Player passwords are hashed with BCrypt
- Session-based authentication throughout; Spring Security form login is disabled in favor of a custom controller flow
- Rate limiting on the admin login endpoint via Bucket4j (5 attempts before a 30-minute lockout)
- No sensitive game data (answers, clues) is exposed in the HTML; all validation is server-side
- API keys and secrets are stored in environment variables, not in source code

## Running Locally

**Prerequisites:** Java 17, Maven, PostgreSQL

1. Clone the repository
2. Create a PostgreSQL database
3. Copy `application.properties.example` to `application.properties` and fill in your values
4. Add the following keys to your properties file:

```
spring.datasource.url=jdbc:postgresql://localhost:5432/yourdb
spring.datasource.username=youruser
spring.datasource.password=yourpassword

groq.api.key=your_groq_key
groq.api.url=https://api.groq.com/openai/v1/chat/completions

unsplash.api.key=your_unsplash_key
unsplash.api.url=https://api.unsplash.com/search/photos

admin.password=your_admin_password
admin.totp.secret=your_base32_secret
```

5. Generate a TOTP secret: `python3 -c "import base64, os; print(base64.b32encode(os.urandom(20)).decode())"`
6. Run the application: `mvn spring-boot:run`
7. Visit `http://localhost:8080/admin/setup` and scan the QR code with an authenticator app
8. From that point forward, use `/admin/login` to access the admin panel
